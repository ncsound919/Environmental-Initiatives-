# KPIs & Test Plan
## KPIs
- EPS: monomer purity ≥90% or styrene‑range ≥70 wt%.
- Oil: Cl ≤ 50 ppm; water ≤ 0.1 wt%; metals per spec; distillation reproducibility within ±2 °C at cut points.
- Emissions: within permit; zero flaring except safety.
- Micromobility: $/mile ≤ gasoline scooter baseline; uptime ≥ 97%.

## 60–90 Day Test Plan
1) Bench EPS depolymerization runs; condenser cut characterization; solvent recycle measurement.
2) Polyolefin oil polishing runs across 3 adsorbents; define bed lives vs chlorine/metals.
3) Blending trials to hit two buyer specs: “cracker feed” and “industrial fuel” (where lawful).
4) CEMS shakedown + public dashboard; interlock tests.
5) Pilot e‑scooter swap cabinet tied to plant power; publish waste→kWh→miles accounting.
