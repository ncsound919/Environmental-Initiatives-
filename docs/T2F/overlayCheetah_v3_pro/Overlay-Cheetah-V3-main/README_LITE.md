## 📦 Quick Start

### Installation

```bash
# Clone or download this repository
cd Overlay-Cheetah-V3

# Install optional dependencies (recommended for parsing generated YAML)
pip install pyyaml

# Run the Lite version
python overlay_cheetah_v3_lite.py
```

**Note**: PyYAML is optional but recommended if you want to parse the generated YAML files with external tools.

### First Use

1. **Welcome Wizard**: On first launch, you'll see a friendly onboarding wizard
2. **Choose Template**: Select from 3 basic starter templates
3. **Create Project**: Enter your project name and details
4. **Generate & Build**: Create your basic project template

## 🔧 Technical Details

### System Requirements
- **OS**: Windows 10+, macOS 10.14+, Linux (Ubuntu 18.04+)
- **Python**: 3.7 or higher
- **RAM**: 512MB minimum
- **Disk**: 50MB for Lite version

### Dependencies
- Python 3.7+
- Tkinter (usually included with Python)
- PyYAML (optional, for parsing generated YAML)

### File Structure
```

settings_lite.json            # Your settings (auto-created)
```
